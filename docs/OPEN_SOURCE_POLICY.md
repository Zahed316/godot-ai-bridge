# Open Source Policy

This project is intended to remain clean, auditable, and license-safe.

Rules:

- A public GitHub repository does not automatically mean unrestricted reuse.
- The license file controls reuse.
- MIT-compatible code may be reused with attribution and notice preservation.
- Proprietary or paid package code must not be copied.
- Public README ideas may be used for benchmarking and roadmap planning.
- Any copied MIT code must be documented in `THIRD_PARTY_NOTICES.md`.
- Prefer original implementation unless direct reuse has clear value.
- Keep implementation provenance clear enough for review.

For `youichi-uda/godot-mcp-pro`, the public Godot plugin under `addons/godot_mcp/` is MIT licensed. Its TypeScript MCP server is proprietary and is not reusable for this project.
