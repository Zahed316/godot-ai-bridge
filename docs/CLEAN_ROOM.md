# Clean Room Policy

This project must remain original work.

- Implementation must be written from scratch for this repository.
- Public repositories may be used only for benchmarking and for understanding public APIs and behavior.
- Do not copy proprietary code from `godot-mcp-pro`.
- Do not copy the paid server implementation.
- If MIT-licensed code is ever reused, preserve the required license attribution and notices.

If there is any doubt about provenance, treat the material as non-reusable until it is independently reimplemented.
